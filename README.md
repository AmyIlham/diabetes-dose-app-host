# جرعتي · Ma Dose

Insulin & carbohydrate dose calculator — Arabic & French PWA.

## Features
- Insulin-to-Carb Ratio (ICR) and Insulin Sensitivity Factor (ISF) calculator
- Food database (raw foods + Algerian dishes) + barcode scanner (Open Food Facts)
- Custom meals ("My Meals") with persistent storage
- Correction dose calculator
- Statistics (glucose, TIR, HbA1c estimate)
- Offline-capable PWA

## Usage
Open `index.html` in any browser. Works offline after first load.

## Live URL
Enable GitHub Pages to get a permanent URL for PWA installation.
